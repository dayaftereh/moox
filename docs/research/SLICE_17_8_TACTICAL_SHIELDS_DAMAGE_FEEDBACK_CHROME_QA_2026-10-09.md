# Slice 17.8 - Tactical shield indicator and damage feedback

Date: 2026-10-09
Status: implementation and automated QA complete, manual User Review still required.

## Request and authoritative contract

The player wants to see whether ships still have shields, and tell apart actual shield, armor/hull and structural damage. Use the authoritative Tactical snapshot and `battle_damage_applied` event deltas rather than inventing damage values.

- Blue circle: draw around non-destroyed ships if **any of four** `shield_arc_current` entries is strictly greater than zero. The circle uses `data-shield-current` = arc sum and `data-shield-max` = `shield_arc_max * 4`; ring opacity conveys total charge. No ring for zero charge or destroyed ships.
- Blue floating `-N` = sum of positive `shield_before - shield_after` from real damage applications.
- Yellow floating `-N` = positive `armor_before - armor_after` (actual armor/panzerung, not raw incoming damage).
- Red floating `-N` = positive `structure_damage_after - structure_damage_before` (internal structure damage).
- A Shield-hit flash is presented only if real shield charge was lost. When all four authoritative arcs are empty, the circle disappears and the shield-break pulse is enabled at the hit.
- No fabricated red structure loss fallback when a Beam hit reports raw damage without attributable loss in any layer.
- Presentation/camera/active-ship movement overlays must preserve existing Slice 17.8 behavior.

## Coverage

- Beam: existing `beam_fired` / `beam_volley_resolved` damage event join shares a single layer-delta helper and draws only authoritative layers.
- Fighter/Bomber: `fighter_attack_resolved` joins `battle_damage_applied` by command sequence, fighter group ID, target and preceding group attack boundary; one color-labelled number per actual layer.
- Missile: `projectile_impact_resolved` joins its later `battle_damage_applied` applications by command sequence, projectile ID, impact index and target ship. It queues a short standalone impact cue with the computed numbers and shield hit flash.
- Ordnance, Fighter and Beam shots without shield charge loss do not pretend shields were depleted. The existing `projectile` feedback palette for point defense remains unchanged.
